# Lettimo 英语

**每天一点，英语更进一步。**

一个面向个人学习的英语练习网站，把自然拼读、单词积累和语法练习放在一起。从字母发音开始，逐步学会读单词、记词义和理解句子。

**在线体验：[打开 Lettimo 英语](https://chaichuanfa.github.io/lettimo-english/)**

> 本项目供个人学习与非商业使用，不能用于商业目的。许可范围见 [LICENSE](LICENSE)。

## 可以学什么

- **自然拼读**：10 个阶段、63 节课，涵盖字母发音、常见字母组合和多音节单词，配有发音、例句和课后测验。
- **单词学习**：中考词汇（含小学）、高考、四级、六级词书，支持生词本和间隔复习；默认每天 10 个新词，先复习再学新词。
- **语法练习**：77 节课，按小学、初中、高中学段筛选，结合规则讲解、例句和测验逐步学习。
- **查词与复习**：约 4 万词的拼读词典，提供释义、音标和拼读拆解；错题与待复习单词集中练习。
- **日常积累**：每日一句与每日小挑战，支持电脑、手机访问和深色模式。

无需注册。学习进度保存在当前浏览器，清除网站数据会丢失记录，不会自动跨设备同步。词书按词典的考试标签整理，不是官方考试大纲词表。

## 本地运行

使用 **Node.js 22.12+**（推荐 24）。

```bash
git clone https://github.com/chaichuanfa/lettimo-english.git
cd lettimo-english
npm ci
npm run dev
```

打开 [本地网站](http://127.0.0.1:5173/)。项目使用 React、TypeScript 和 Vite，构建后可作为静态网站部署。

```bash
npm run build    # 构建到 dist/
npm run preview  # 预览生产构建
npm test         # 运行核心测试
```

仓库已配置 GitHub Pages 自动部署，推送到 `main` 后发布。自行部署时仅上传 `dist/`；若部署在子目录，构建时设置 `SITE_BASE`，例如 `SITE_BASE=/lettimo-english/ npm run build`。
